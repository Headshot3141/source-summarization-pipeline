# Settled Decisions

Every agent that writes, reviews, or edits a summary reads this file: the General section and the section for its source slug. It holds the rulings the coordinator or the user has made, so agents stop reporting them and never undo them. In one run, fix agents undid two misprint rulings that sat only in an earlier pass's brief.

Keep each entry to one line: the ruling, then who made it and when. Add an entry whenever a question is settled; remove nothing (mark a reversed ruling as reversed, with the date). The coordinator also logs each decision in `plan.md` (Project Status).
